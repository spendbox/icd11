Reading a code

Anatomy of a code

Same disease — P. falciparum malaria, cerebral — in each system.

ICD-10
B50.0
  • B — chapter (infectious, A00–B99)
  • 50 — category (falciparum malaria)
  • .0 — detail (cerebral)

1 letter + digits. Little room to grow.

ICD-11
1F40.0
  • 1 — chapter (01 Infectious)
  • F — block (2nd char is always a letter)
  • 40 — category (falciparum malaria)
  • .0 — detail (cerebral) · can also cluster extensions

Letters O and I are never used — no confusion with 0 and 1.

    An honest appraisal

    ICD-11: pros & cons

    ✓ Pros

    • Greater precision via clustering.
    • Digital-native: API + coding tool.
    • Always current; globally comparable.

    ! Cons

    • Learning curve for ICD-10 staff.
    • Needs tooling & connectivity.
    • Not tuned to our local burden.
    That last gap — local fit — is what HCD closes.

    Our proposal

    Introducing HCD

    A light, local layer on top of ICD-11 — never a replacement.

    🦟

    Tuned to our burden

    ICD-11 compatible

    Under the hood

    How an HCD code is built

    HCD-COM-01.Pf
    HCD — namespace
    COM — chapter (Communicable)
    01 — condition (Malaria)
    Pf — local modifier (P. falciparum)
    HCD code HCD-COM-01.Pf Malaria — falciparum
    maps to →
    ICD-11 (auto-stored) 1F40 Malaria due to P. falciparum
