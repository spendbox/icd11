What is the ICD?

🌍

A common language

📊

The 2022 standard

ICD-11 — built for the digital age

The first edition designed to live inside software, not books.

  • One living database (the Foundation) — updated continuously.
  • Post-coordination — combine a stem code + extension codes for precision.
  • Digital-native — an official API and a drop-in coding tool.
  • Vast but searchable — you search, you don’t memorise.

How it actually works

ICD-11 inside the EMR

You don’t memorise codes — you search, pick, refine. Here is the machinery.

🔌

Official ICD-API

WHO hosts a live REST API at id.who.int (OAuth2). The EMR queries it for every search and code.

🔎

Embedded Coding Tool

A drop-in WHO JavaScript widget: type a term → ranked matches → pick the code. Search-as-you-type.

⚡

Autocode

Send free text (“high fever, +ve RDT”) and the API returns the closest-match code.

📡

Works offline

The API can run on a local server/container — vital where connectivity is poor.

So diagnosis coding is via search, backed by the API — not a paper index. (Try it on the Live Demo slide.)

An honest appraisal

ICD-11: pros & cons

✓ Pros

  • Greater precision via clustering.
  • Digital-native: API + coding tool.
  • Always current; globally comparable.
  • Interoperable with SNOMED CT.

! Cons

  • Learning curve for ICD-10-trained staff.
  • Needs tooling & connectivity.
  • Migration & retraining cost.
  • Not tuned to our local burden.
That last gap — local fit — is what HCD closes.

Our proposal

Introducing HCD

The Harvey-road Classification of Diseases — a light, local layer on top of ICD-11.

Not a replacement. Every HCD code maps 1-to-1 to a valid ICD-11 cluster — globally compatible, but faster and locally meaningful.

🦟

Tuned to our burden

Our top ~50 conditions — malaria, typhoid, sickle cell — one tap away.

⚡

Fast at the OPD

Short codes (HCD-COM-01 = malaria) cut clicks and errors.

📍

Local context

Season, RDT vs clinical, catchment — data ICD-11 alone won’t surface.

🔁

ICD-11 compatible

Stores the ICD-11 cluster, so NHIS/global reporting is automatic.
