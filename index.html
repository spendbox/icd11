Reading a code

Anatomy of a code

Same disease — P. falciparum malaria, cerebral — in each system.

ICD-10
B50.0
  • B — chapter (infectious, A00–B99)
  • 50 — category (falciparum malaria)
  • .0 — detail (cerebral)

1 letter + digits. Little room to grow.

ICD-11
1F40.0
  • 1 — chapter (01 Infectious)
  • F — block (2nd char is always a letter)
  • 40 — category (falciparum malaria)
  • .0 — detail (cerebral) · can cluster extensions

Letters O and I are never used — no confusion with 0 and 1.

Combine a stem code with extension codes to add detail — instead of a separate code for every case.

The extension toolbox

Chapter X — the extension codes

ICD-11 keeps every extension in one place: Chapter X, around 1,400 codes grouped by what they describe.

Lateralityleft · right · bilateral Severitymild · moderate · severe Temporality / courseacute · chronic · recurrent · in remission Anatomy & topologyspecific site · proximal/distal · upper/lower Aetiology / causal agentorganism · substance · external cause Histopathologytissue / cell type Dimensions of injuryopen · closed · displaced Diagnosis certaintyconfirmed · suspected · provisional
One stem can take several extensions at once — that combinatorial reuse is how ~17,000 stem codes express the WHO’s 1.6 million+ codable situations.

      The real-world problem

      A diagnosis is not a single moment

      On the ward it changes by the hour — and we can’t let coding slow down care.

      ⏱️

      Fast at the point of care

      A clerking has several problems at once. Capturing them must take seconds, not minutes — or clinicians simply won’t do it.

      🔄

      It evolves

      “Query sepsis” becomes confirmed; hypertension goes from uncontrolled to stable. The record has to move with the patient.

      🩺

      Diagnosis ≠ assessment

      “Stable”, “improving”, “for review” are assessments of a known problem — not diagnoses, and not ICD codes.

      🧾

      Our EMR today

      Has a single Diagnosis field. There is nowhere to record the day-to-day assessment — so nuance is lost or jammed into the wrong box.

      The fix is two fields, not one: a coded Diagnosis and a free Assessment / clinical course beside it.

      A local idea

      Do we need an “HCD”?

      HCD — a Harvey Road Classification of Diseases: our own local code list, shaped around how we actually work.

      ✓ The appeal

      • Tailored to our common presentations.
      • Short codes staff can learn quickly.
      • Room for local concepts ICD may not name.

      ! What it would take

      • Author & maintain the whole code set ourselves.
      • Build a crosswalk mapping every HCD code back to ICD-11 (for NHIS/HMO, stats, research).
      • Governance, versioning, training — forever.
      • It stays local: not comparable beyond our walls.

      In short: HCD solves the speed/assessment problem by rebuilding a classification from scratch — a large, permanent maintenance burden, and an island of data.

      The better path

      Keep the global standard — just use it well

      We can get everything HCD promised without maintaining our own classification: adopt ICD-11 in a context-aware way and add the missing assessment field.

      What we wantBuild HCDContext-aware ICD-11
      Speed at point of careYes (new codes to learn)Yes — search & shorthand (“T2DM”)
      Right detail, no clutterHard-coded per diseaseOnly relevant extensions suggested

      Comparable & billableNeeds a crosswalkNative — it already is ICD-11
      Proposed solution: a fast diagnosis coder that suggests context-aware extensions, plus an assessment field for the clinical course. The assessment is typed manually — and for anything not yet diagnosed, we can query it.

      The honest trade-off

      “Won’t careful coding slow us down?”

      Coding one diagnosis well costs a few extra seconds. The win comes when the same pattern — natural language plus confirmation pills — runs the whole encounter.

      🩺

      Diagnosis

      Type it, tap the context-aware ICD-11 cluster. Coded as you think.

      💊

      Prescriptions

      Type the order, tap to confirm — it syncs straight to the pharmacy. No second screen, no tick-boxes.

      🧪

      Investigations

      Type the tests, tap to confirm — synced to the lab. One field, not a form.

      3–5×faster overall workflow

      An honest appraisal

      ICD-11: pros & cons

      ✓ Pros

      • Greater precision via clustering.
      • Digital-native: API + coding tool.
      • Always current; globally comparable.

      ! Cons

      • Learning curve for ICD-10 staff.
      • Needs tooling & connectivity.
      • Migration & retraining effort.
